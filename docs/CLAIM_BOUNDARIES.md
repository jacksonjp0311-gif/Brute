# BGR v0.90 — Scientific claim boundaries

**Verified bounded claim:** n≤4 stationary deterministic hidden Moore-machine support is exact relative to a supplied complete model family; 360 in-grammar cases and 15,840 action steps produced zero false conditional certificates, with independent prefix reconstruction. A model-family membership assumption is mathematically necessary for soundness. An n=5 or drifting model is not thereby ruled out from finite experience.

**Verified model-size expansion:** on 72 previously out-of-family four-state cases, the legacy n≤3 conditional rule emitted 78 incorrect claims; the expanded n≤4 rule emitted zero, while remaining consistent with all observations. Both versions were tested against the same masked trajectories. The broader n=5 + drift families still caused 140 *conditional* false claims.

**Public proof boundary:** no external attestation was provided; outward-facing proofs are **always withheld** in this study. This achieves zero incorrect PUBLIC certificates by total abstention. It is NOT a learned OOD detector, verified model adequacy, or production permission security. The `scope_verified` flag is only a controlled laboratory proxy and must not be treated as secure authority.

**Quotient claim:** standard Moore minimization identifies equivalent states for a fully known machine iff every future action sequence yields the same outputs. Verified on 120 complete held-out worlds, including alias counterexamples and permutation invariance. It does not yet infer the true minimal machine from incomplete masked observations.

**Computational claim:** partial reachable transition constraints avoided explicit enumeration of 16,777,216 complete labelled four-state models. Max partial rows observed 4,089, but this is NOT a directly comparable memory or energy savings factor.

**Impossibility witness:** any finite action/observation trace admits larger deterministic Moore machine completions with diverging next observations. Therefore unrestricted universally sound certification cannot follow from a finite trace alone.

**No demonstration:** arbitrary grammar discovery, stochastic delayed or changing worlds, positive transfer in the novel hidden-world setting, independent third-party replication, calibrated open-world confidence, AGI, hardware BitWatts or language capability.
