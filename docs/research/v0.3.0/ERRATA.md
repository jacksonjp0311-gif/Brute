# Brute v0.3.0 errata (2026-10-25, EDT)

Source: an independent cold review of tag `v0.3.0` (read-only, by a separate reviewer agent; it found **no number
mismatches**, reproduced the sealed files, the reproducibility check and the full reference run). This errata changes
**documentation and adds new checks only**. The tag `v0.3.0` (`73a3a5a`), the sealed study-005 results, the plan, the
scoring scripts and every frozen file are unchanged. Labels: Exact / Observed / Simulated / Inferred / Rejected / Open.
