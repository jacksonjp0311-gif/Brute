# BGR v0.90 — Quick directory

The root [README](../README.md) is the canonical user-facing entry with full directory. [WHITEPAPER](../WHITEPAPER.md) states assumptions and proofs. New research lives in `bgr90/`, with `symbolic.py` for first-visit hidden model constraints, `adequacy.py` for guarded forecasts, `quotient.py` for complete-machine predictive minimization, `worlds.py` for evaluator-only adversarial families, and `evaluation.py` for sealed paired tests. `experiments/v90_independent_reference.py` independently reconstructs supports; `experiments/independent_audit.py` replays and seals findings. Legacy regressions remain in original `bgr60…bgr89/` and `tests/test85…test89.py`. `baseline/BGR-v0.89.0.zip` is the complete unchanged previous release. `results/` contains both negative stress receipts and verified findings. `scripts/open_world_counterexample.py` constructs independent unrestricted-world counterexamples. `ui/` is a strictly read-only viewer of original observations, with graphical assets under `assets/`.
