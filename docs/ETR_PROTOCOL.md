# Executable Theory Refinement (ETR)

A version is an experimental artifact, not a claim of broader intelligence. For each BGR iteration: state a falsifiable hypothesis; formalize invariants and failure modes; implement runnable software; perturb with counterexamples; preregister and freeze untouched evaluation seeds; run matched baselines and report costs; audit independently; retain rejected hypotheses, counterexamples and complete predecessor; version the README, whitepaper, code, experiments and next plan in one folder/ZIP.

**No promotion without evidence.** The v0.84 result demonstrates why: an implemented, correctly tested epistemic branch selector did not beat the simpler v0.83 frontier baseline at equal action budgets. It stays experimental.

No model may grant itself external authority or promote unverified skills. All hardware measurements require true instrumentation. Only BGR source is in scope.
